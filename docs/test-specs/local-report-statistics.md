# Scoped report statistics

This follows M26 quantile batching in #8644. The five report consumers need
only mean, population standard deviation and the legacy quantile definition.
The local module preserves those operations, including scalar/array quantiles,
empty results, sorted-copy behavior and arithmetic order. Population deviation
accumulates squared differences without allocating the old temporary array.
It does not adopt D3's different percentile interpolation or change rounding.

`tests/fixtures/report-statistics-oracle.json` contains results generated by
an independently installed simple-statistics 0.7.0, not by the replacement.
The 109 samples cover empty/single/even/odd/repeated/unsorted/decimal/negative
and large-offset values plus deterministic samples of lengths 1 through 100.
Run `node tools/generate-report-statistics-oracle.js /absolute/path/to/simple-statistics`
to reproduce it; the generator checks the installed version. The suite checks
exact mean, deviation, seven scalar and batched quantiles, and frozen inputs.
Together with existing quantile contracts, 118 cases pass on Node 22.23.2 and
24.20.0. Targeted Chromium report validation passes all 18 cases, covering
Daily Stats, percentile/hourly plots and tables, cached rendering, both units,
DST gaps/overlaps and legacy reports. Full backend and hosted checks remain
required, as does integration of the preceding batching PR.

Clean npm ci and production build pass. Removing the declaration removes one
installed package path with no added or changed retained lock entries. Its
installed regular files total 661,926 bytes. Compared with the batching parent,
reports JavaScript is 6,660 bytes smaller (2,506 bytes smaller with Python gzip);
admin/app/clock/food/profile JavaScript is byte-identical. These are bundle and
installed-file measurements, not a server-memory saving. Report plugins run in
the browser. Retained heap and full-render CPU have not been measured.

The implementation is adapted from the installed library and retains its full
BSD license notice in the source. Production compilation extracts that notice
into `bundle.reports.js.LICENSE.txt`. The historic quantile baseline JSON still
records the original 0.7.0 measurements; the measurement tool now identifies the
local implementation when generating new results.

Rollback restores the five imports, manifest/lockfile and old measurement/test
imports together. No stored data, report options or UI workflow changes.
